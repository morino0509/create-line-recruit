# CREATE LINE｜採用サイト

イベントプロデュース会社「CREATE LINE」の採用サイトです。

ホテルイベントを中心に、企画・制作・運営・空間演出までを一貫して手掛ける架空のイベントプロデュース会社を設定し、企業の世界観や魅力、働く人の姿が伝わる採用サイトを制作しています。

## プロジェクト概要

- **制作期間：約1.5か月**
- **制作目的：自主制作（ポートフォリオ用）**
- **サイト種別：コーポレート・採用サイト**
- **デザイン・設計：Figma**
- **使用技術：HTML / CSS / JavaScript / jQuery / Slick**
- **制作状況：制作中**

## 制作の目的・コンセプト

企業のブランドイメージを伝えるだけでなく、求職者が仕事内容や社風、働く環境を具体的にイメージできる採用サイトを目指しました。

ホテルライクな上質さと親しみやすさを組み合わせた「ラグジュアリーポップ」をデザインコンセプトに設定。

写真や余白、配色、タイポグラフィを工夫し、企業の世界観を統一しながら、情報を整理して伝えられる構成を意識しています。

## サイト構成

| ページ | 内容 |
| --- | --- |
| TOP | 企業紹介、事業内容、職種紹介、社員紹介 |
| ABOUT | 企業理念、事業内容、会社情報 |
| JOBS | 4つの職種紹介、仕事内容の詳細 |
| RECRUIT | 募集要項、採用フロー、FAQ |
| ENTRY | 応募フォーム |

## 担当範囲・制作工程

企画・情報設計からデザイン、コーディングまで一貫して担当しています。

1. **企画・情報設計**
   - サイトの目的とターゲットの設定
   - 掲載コンテンツの整理
   - ページ構成・導線設計

2. **ワイヤーフレーム・デザイン**
   - Figmaでワイヤーフレームを作成
   - デザインカンプの制作
   - 配色・フォント・画像の選定

3. **コーディング**
   - HTMLによるマークアップ
   - CSSによるレイアウト構築
   - JavaScript・jQueryによる動的表現の実装

## 工夫したポイント

- **情報設計：** 求職者が知りたい情報をページごとに整理し、仕事内容から募集要項、応募まで自然に読み進められる構成を意識しました。
- **デザイン：** 上質さと親しみやすさを両立させ、企業のブランドイメージに統一感を持たせました。
- **コンテンツ：** 職種ごとの仕事内容を具体的に掲載し、入社後の働き方をイメージしやすい内容にしました。
- **UI・UX：** 各ページへの導線や情報の優先順位を意識し、ユーザーが迷わず目的の情報へアクセスできるように設計しました。

## JavaScriptによる実装

- **Slick：** スライダーを実装し、コンテンツを視覚的に見せる構成にしました。
- **スクロールアニメーション：** スクロール位置に連動したアニメーションを実装しました。
- **FAQ：** jQueryを使用し、クリック操作で回答を開閉できるようにしました。
